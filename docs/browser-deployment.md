# Public browser deployment retired

The owner retired the public deployment template and user-led, one-click Cloudflare deployment on 30 September 2026. The project now maintains one private repository and an owner-operated installation.

The old Deploy-to-Cloudflare button and setup instructions are intentionally removed from this active guide. Their historical versions remain in Git and the private handover archive. Retiring distribution does not authorise deleting an existing user's data or changing the current application's Access protection.

For the maintained installation, use [deployment and rollout](deployment.md). Generic configuration and legacy native sign-in code remain while their dependencies are reviewed; their presence does not reopen the public product/distribution path.
